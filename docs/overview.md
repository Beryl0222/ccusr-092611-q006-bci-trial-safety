# 脑机试验安全记录说明

脑机试验安全记录需要在多方参与、事件顺序不稳定和服务重启的情况下保持记录一致。每条记录有所属方、状态和递增版本，所有状态变化写入事件表；请求键用于抵御重复提交，事务失败时整次写入回滚。

试验会话服务（trial.py）在此之上固化了试验安全不变量：授权与当前参数版本下的有效校准完成前，控制指令只被拒绝并留痕；紧急停止在同一事务内抢占全部未执行的排队指令，延迟到达的旧指令无论是重放还是新序号都无法越过停止；指令按（会话，序号）幂等，重放只返回已记录的结果；设备参数变更使参数版本递增，旧校准立即失效；研究人员与临床人员分别受限于获准的受试者范围，授权仅限临床人员；所有状态变化写入带哈希链的事件表，服务重启后仍保持停止状态、指令结果与审核证据，并可按时间顺序导出复核、用 verify_chain 校验完整性。
